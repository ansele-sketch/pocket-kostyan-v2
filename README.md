# Карманный Костян — Telegram Mini App starter

Это готовый к запуску проект веб-игры с адаптацией под Telegram Mini Apps:
- главное меню с тремя реальными фото-образами Костяна;
- чат с локальными репликами, а при настройке `OPENAI_API_KEY` — серверный ИИ-чат;
- системная русская озвучка браузера;
- бегалка на три полосы со сбором монет и препятствиями;
- гардероб, еда, спортзал, характеристики и сохранение прогресса в localStorage;
- Telegram WebApp SDK (`ready()` / `expand()`).

## Запуск локально

Нужен Node.js 20+.

```bash
npm install
cp .env.example .env
# добавь ключ в .env, если нужен ИИ-чат
npm start
```

Открой `http://localhost:3000` в браузере. Без ключа игра работает на локальных ответах.

## Подключение ИИ

В `.env`:
```
OPENAI_API_KEY=твой_секретный_ключ
OPENAI_MODEL=gpt-4.1-mini
PORT=3000
```

Никогда не вставляй секретный ключ в HTML или клиентский JavaScript. Сервер читает его из переменной окружения.

## Публикация как Telegram Mini App

Telegram Mini App должен быть доступен по HTTPS. Разверни проект на любом Node-хостинге, который поддерживает переменные окружения и Node.js (например, Render, Railway или свой сервер), добавь `OPENAI_API_KEY` в настройках хостинга, затем:

1. Создай бота через `@BotFather`, если его ещё нет.
2. В настройках бота открой настройку Mini App / Main App или меню и укажи HTTPS URL развернутого приложения.
3. Открой бота в Telegram и запусти Mini App.

`telegram-web-app.js` и вызовы `Telegram.WebApp.ready()` / `expand()` уже добавлены. Для продакшена с платёжами, таблицей лидеров или проверкой Telegram-пользователя понадобится серверная валидация `initData`; не доверяй данным пользователя из клиента.

## Что ещё не является финальной AAA-версией

Это играбельный starter, а не нативная 3D-игра: фотографии используются как портретные образы, а выбор одежды переключает доступные образы, не накладывая отдельные текстуры одежды на модель. Для полноценного скелетного движения, мимики и настоящего переодевания нужны отдельные согласованные спрайты/модель и набор анимаций. ИИ-чат требует собственного API-ключа и хостинга — это нельзя включить в статический HTML безопасно.
